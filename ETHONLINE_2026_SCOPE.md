# ETHOnline 2026 — Continuity Track Scope & Milestone Checklist

## 🟢 Built BEFORE ETHOnline 2026 (Foundation Layer — Fork Baseline: rezon99/BlotChain)
Base spatial visualizer repository fork: [https://github.com/rezon99/BlotChain](https://github.com/rezon99/BlotChain)

- **2D SVG Spatial Graph Visualizer:** Interactive node layout with drag-and-drop physics, node selection, custom connection particle animations, category filtering, and responsive SVG viewport adaptation.
- **3D Three.js WebGL Dashboard:** 3D space rendering for tokens and liquidity nodes with animated flow particles, orbit camera controls, dynamic glow materials, and lighting effects.
- **WebXR VR Mode:** Immersive spatial VR viewport supporting VR headsets, 3D spatial node inspection, and immersive graph interactions.
- **Real-Time CoinGecko Market Polling:** Integrated live price and liquidity polling for Crypto assets and NFT collections with configurable polling frequencies and local storage state persistence.
- **Interactive Analytics & Side-by-Side Comparison:** Multi-node comparison panel (price, 24h/7d change, volume, liquidity), sparkline history charts, and interactive ripple cascade visual feedback.
- **Canvas Snapshot & State Export:** Export full network topology to high-resolution PNG images and structured JSON exports.
